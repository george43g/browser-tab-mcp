## Session lessons worth not relearning

- **Rebuilding on the wrong branch invalidates a browser reload.** It happened
  twice; the second time cost a wasted user reload, because `pnpm build` during
  another PR's verification overwrote `apps/chrome-extension/dist/`. Check
  `doctor`'s `daemon build` line and the extension stamp before trusting any
  live check.
- **`chrome.windows.update` resolves on ACCEPT, not completion**, and
  `windows.get().state` reports the requested state *optimistically* — so there
  is no completion signal to poll. A fix that polled it passed its unit tests
  and was a live no-op.
- **yabai re-tiles managed windows**, so bounds assertions are meaningless here.
  Assert on state.
- **Agents must run in isolated worktrees.** A background agent from another
  session mutated this working tree mid-task; the isolation is what stopped that
  from clobbering uncommitted work.
