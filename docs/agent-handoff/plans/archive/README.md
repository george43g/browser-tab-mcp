# Archived plans — shipped, kept for the reasoning

A plan lands here when its goal is **verifiably in the repo** — not when its
own status line says so. Every file here carries a dated `STATUS` line naming
the file and line where the shipped thing actually lives, so the claim can be
falsified without re-deriving it.

Two plans deliberately did NOT move, and the reason is the useful part:

- `../2026-08-21-cg-oscillation-instrumentation.md` is **half done** —
  instrumentation shipped, the measurement-gated fix did not — and its M1–M4
  decision table is still the live reference for an open BACKLOG bug.
- `../2026-08-22-command-sweep-research-brief.md` is terminal but cited BY PATH
  from three live documents, one an append-only progress-log entry that must
  not be reworded.

Archiving is not deletion: `PROGRESS-LOG.md` refers to these by slug, and the
reasoning in them is why several decisions look the way they do.
