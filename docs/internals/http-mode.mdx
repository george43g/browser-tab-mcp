See [`HTTP_MODE.md`](https://github.com/george43g/mcp-cli-starter-template/blob/main/docs/HTTP_MODE.md) in the repo for the full guide. Quick reference below.

## Enable

```bash
export MCP_HTTP_TOKEN=$(openssl rand -hex 32)
browser-tab mcp --http --port 8080 --bind 127.0.0.1
```

## Endpoints

| Path | Auth | Description |
|------|------|-------------|
| `POST /mcp` | Bearer | The MCP Streamable HTTP endpoint. Echo `mcp-session-id` from `initialize` on subsequent requests. |
| `GET /health` | None | Health snapshot for reverse-proxy probes. Returns 503 if unhealthy. |

## TLS

Bind defaults to `127.0.0.1`. Terminate TLS at a reverse proxy (Caddy, nginx, Cloudflare Tunnel) — the Node process should never accept untrusted connections directly.

## Delete HTTP support

Delete `src/commands/http.ts`. The header in that file lists every dependent reference to remove.
